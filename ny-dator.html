Koppla in en ny dator

Tre saker, i ordning. Del 1 och 2 gör du vid den nya datorn, del 3 klistrar du in i Claude. Sedan sköter maskinen sig själv. Maskin-id nedan är nästa lediga, byt om du vill.

1

Det här måste finnas först

  • Ett eget Claude-konto. Delar två datorer samma konto delar de samma tak, och ni får ingen extra kapacitet alls.
  • Git, Python och Claude Code installerade.
  • Kopplingar i det nya Claude-kontot: Shopify (obligatorisk), Google Drive (image ads), Chrome-tillägget (Firefly och Creative Loop).
  • Starta Claude Code en gång i mappen C:\Users\<du>\Downloads\Claude CODE och stäng den. Det skapar mappen som steg 2 kopplar minnet till.
2

Fyra kommandon i PowerShell

git clone https://github.com/elliot851/soldahl-machine.git C:\soldahl-machine
cd C:\soldahl-machine
powershell -ExecutionPolicy Bypass -File tools\setup-machine.ps1 -MachineId M3
powershell -ExecutionPolicy Bypass -File tools\sync.ps1 hello
Klistra in i PowerShell. Logga in som elliot851 när GitHub frågar.
3

Första meddelandet till Claude

Starta Claude Code i samma mapp och klistra in exakt det här. Det är den enda prompten som behövs.

Du ar maskin M3 i Soldahls maskinpark.

Las C:\soldahl-machine\PROTOCOL.md forst. Den ar bindande arbetsordning
och gar fore din egen bedomning. Las sedan
C:\soldahl-machine\memory\MEMORY.md och
C:\soldahl-machine\runbook\00-START-HAR.txt.

Kor sedan:
powershell -ExecutionPolicy Bypass -File C:\soldahl-machine\tools\sync.ps1 pull

Las det pull skriver ut under NYHETER. Det ar andringar de andra
maskinerna gjort som galler dig.

Ta darefter nasta produkt ur Accepted Elliot som ingen annan maskin redan
har claimat. Claima den med sync.ps1 claim <handle>. Far du exit 2 ar den
upptagen, ta nasta. Preflight-kolla handlen i Shopify innan du borjar, och
bygg sedan enligt runbook\STEGKEDJA.txt fran STEG 0.

Under bygget:
- Kor sync.ps1 pull fore VARJE nytt STEG, och las nyheterna om det kommer nagra.
- Kor sync.ps1 progress <handle> <steg> "notering" efter VARJE avklarat STEG.
- Pusha lardomar med sync.ps1 push "vad du lart dig" DIREKT nar nagot ar lost,
  inte samlat pa slutet.
- Slapp produkten med sync.ps1 release <handle> nar den ar klar.

Full autonomi. Fraga mig inte om varje steg, kor och rapportera i slutet.
Sedan kör maskinen själv enligt protokollet.
+

Har maskinen varit av ett tag?

Ingen ny installation. Skicka bara det här, så hämtar den allt nytt själv.

Kor powershell -ExecutionPolicy Bypass -File C:\soldahl-machine\tools\sync.ps1 pull
och las nyheterna den skriver ut. Kor sedan sync.ps1 hello, den paminner om
du haller ett claim. Fortsatt darefter enligt PROTOCOL.md.
Fungerar på vilken maskin som helst.

Hela guiden med felsökning finns som text: NY-DATOR.txt. Den och den här sidan byggs ur samma fil, så de kan inte glida isär.
